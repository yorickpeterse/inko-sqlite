# inko-sqlite

[Inko](https://inko-lang.org/) bindings for [SQLite](https://sqlite.org/).

# Requirements

- Inko `main`, for now

# Installation

```bash
inko pkg add github.com/yorickpeterse/inko-sqlite 0.1.0
inko pkg sync
```
